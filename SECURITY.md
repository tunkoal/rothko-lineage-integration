# Security reporting

This is an unofficial development-source project. No security support period,
production certification or official LineageOS acceptance is asserted for this
source candidate. Report the exact source/build baseline and affected feature.

Use this repository's GitHub private vulnerability reporting facility if the
maintainer has enabled it. If it is unavailable, request a private contact channel
without describing the exploit or attaching private data in a public issue.
No maintainer address is invented here; private reporting must be configured
when the real repository is created.

Do not publish authentication templates, private keys, calibration/NV, IMEI,
device serials, personal logs or a working exploit with private user data.
Ordinary reproducible non-security bugs can use the public issue template.
