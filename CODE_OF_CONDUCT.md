# Collaboration conduct

Discuss the code and evidence respectfully. Disagreement about a technical
approach is welcome; personal attacks, harassment and disclosure of another
person's private information are not. Describe problems with reproducible
details and allow others time to investigate.

Keep issues and pull requests focused on the device project. Maintainers may
edit or remove abusive, private-data-bearing or irrelevant material and may
close repeated spam. If an interaction needs private moderation, request a
private channel without posting personal details publicly.
